Spot checks and sampling worksheet

Catalog migration spot checks explains how to count products, variants and SKUs in an export. It ends with a worksheet that shows, as arithmetic on assumed examples, how likely a random sample is to contain a wrong row.

Tracker import files

The files in tracker-import/ are plain CSV with the columns Phase, Check, Details, and Source. They are generated from the checklist files and are under the same CC BY 4.0 licence. Most trackers and spreadsheets can import a CSV.
